# LASERS Masterclass — Interactive B.Sc. Physics Lecture Suite

An interactive, publication-grade digital lecture suite on **LASERS** designed for B.Sc. Physics students and educators. Features hardware-accelerated SVG animations, high-resolution digitized diagrams, real physical laboratory apparatus photographs, interactive teacher pen & laser pointer tools, audio narration, and knowledge check quizzes.

🌐 **Live Website**: [https://bapanayya.github.io/](https://bapanayya.github.io/)

## ✨ Features & Pedagogical Tools

* **🎨 Pure White Modern Aesthetic**: Clear typography, high-contrast text, glossy jewel-tone badges, and generous spacing.
* **⚡ Live Interactive SVG Animations**: GPU-accelerated CSS keyframe animations showing atomic leaps, photon propagation, resonant cavity reflections, and flash lamp pulses. Includes **Play**, **Pause**, **Replay**, and **Show Complete Diagram** toggles.
* **🖼️ 300 DPI Publication-Grade Digitized Diagrams**: High-resolution diagrams rendered specifically for classroom projection and digital whiteboard display.
* **📷 Real Physical Apparatus Galleries**: Authentic laboratory photographs of Theodore Maiman's 1960 Ruby Laser, synthetic ruby rods, operating He-Ne discharge tubes, and modern optics research setups.
* **🖊️ Teacher Pen & Laser Pointer Suite**: Floating, draggable toolbar with freehand pen, semi-transparent highlighter, glowing laser pointer with pulse ripple, eraser, color selector, clear board, undo/redo, and keyboard shortcuts (`Alt+P`, `1`–`5`, `Ctrl+Z`, `Ctrl+Y`, `C`).
* **🔊 Audio Narration**: Built-in speech synthesis allowing students to listen to each unit with high clarity.
* **❓ Interactive Knowledge Checks**: Multiple-choice quizzes reinforcing key concepts with instant feedback and explanations.
